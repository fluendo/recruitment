# Q1.2 — Depth-based filtering for background blur

The goal is to extend the anonymization pipeline with a different layer: blurring background objects in the scene while keeping the foreground sharp. This is useful for hiding identifiable elements that are not the main subject (license plates, signs, secondary people, etc.) without affecting scene utility.

The approach would work as follows:

1. **Depth estimation:** A monocular depth estimation model takes the full frame and produces a depth map — a per-pixel distance estimate of the scene.

2. **Threshold separation:** A depth threshold is applied to classify each pixel as foreground (sharp) or background (blur). Anything beyond the threshold is considered background. The threshold can be static (a configurable parameter) or dynamic (adjusted based on the scene's depth distribution).

3. **Mask + blur:** From that classification, a binary mask is generated and a gaussian blur is applied only to the masked background regions. Foreground remains untouched.

4. **Efficiency:** Background depth is temporally stable — it does not change significantly between consecutive frames. We do not need to run depth estimation on every frame. We can compute the depth map on keyframes (or every N frames) and reuse/interpolate the mask between checkpoints, which drastically reduces the computational cost.
