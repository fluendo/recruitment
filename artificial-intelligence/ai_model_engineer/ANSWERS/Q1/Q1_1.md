# Q_1: Face Anonymization System

## Q_1.1 — Reidentification for selective anonymization while keeping computational cost low

To anonymize only specific individuals, we can extend the existing face detection pipeline with a lightweight reidentification stage, without adding significant computational overhead.

The core idea is simple: we do not need to compare every face in every frame. Instead, we only identify a face **once**, at the moment it first appears, and then track it.

The pipeline would work as follows:

1. **Detection (existing):** The YOLO-style face detector runs as usual and provides bounding boxes for all faces in each frame.

2. **Identification on first appearance:** When a new face is detected that does not yet have an assigned ID, we extract its facial embedding and compare it against a controlled gallery of embeddings belonging to the individuals we want to anonymize (or, conversely, the ones we want to keep identifiable).

3. **Anonymization decision:** Based on the similarity score and a confidence threshold, we decide whether that face should be anonymized or left untouched. The ID and its anonymization flag are assigned to the face.

4. **Temporal tracking:** A lightweight object tracker (based on IoU and a simple motion prediction, e.g. Kalman filter) propagates the assigned ID across frames without re-running the reidentification step. This means the embedding comparison only happens once per face appearance, not per frame.

5. **Lifecycle:** When a face leaves the frame or is no longer detected, its ID is released. If the same person re-enters the scene later, a new ID is assigned and the identification step runs again — which is fine, since it only happens on appearance, not continuously.

This approach keeps the added cost to a minimum: the expensive part (embedding extraction) only runs on newly detected faces, which are typically few per frame. The matching against a small gallery is trivial, and the tracker maintaining IDs across frames is computationally cheap compared to the detector itself.
